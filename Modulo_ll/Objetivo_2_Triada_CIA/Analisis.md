# Triada CIA

## Confidencialidad
Se trata de evitar la exposicion de datos sensibles a usuarios no autorizados
- Ejemplo: Una fuga de informacion donde se filtra una base de datos con salarios, contraseñas
y datos personales.

## Integridad
Es la prevencion de que un codigo, flujo logico o datos de un sistema sufran manipulaciones o alteraciones
de un tercero.
- Ejemplo: Un ataque de inyeccion SQL que permita alterar la base de datos de un servidor.

## Disponibilidad
Es la seguridad de que la aplicacion y sus datos esten activos y accesibles para los usuarios y 
para el negocio.
- Ejemplo: Un ataque de ransomware en el que se cifra la base de datos del sistema impidiendo que se
realice cualquier consulta.
